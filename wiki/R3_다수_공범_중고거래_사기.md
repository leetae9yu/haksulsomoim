# 개요
시드는 공범별 혐의와 배상명령 준비를 적지만, 기소·사건번호·신청 기록은 확인되지 않은 비식별 trace다.

# 처리과정
사기죄는 배상명령 대상 범죄군에 포함될 수 있으나, 해당 공판에서의 유죄 선고와 법정 요건이 필요하다 [CLM-COMPENSATION-0001].

# 결과
신청 준비는 인용, 집행권원 또는 실제 지급을 뜻하지 않는다 [CLM-COMPENSATION-0008].

# 비고
unverified pending trace이며 공범별 처분이나 회수 결과를 일반화하지 않는다. [[전체_사례_목록]]
