# 국내 계좌이체 소액사기 절차 기준

적용 범위는 개인이 변호사 없이 진행하는 3,000만 원 이하 국내 계좌이체 사기 사건이다. 이 문서는 작업 순서를 정할 뿐 법률 결과를 보장하지 않는다. 법령 인용 전에 국가법령정보센터(law.go.kr)에서 현행 조문을 확인한다.

## 사건 접수와 증거

1. 송금 일시·금액·계좌, 거래 경위, 상대방 표시, 연락 경로를 시간순으로 정리한다.
2. 계좌이체 확인증, 대화 원본, 게시물·상품 화면, 신고·상담 기록을 원본 그대로 로컬 보존한다.
3. OCR 결과는 사용자가 원본과 대조해 확인하기 전에는 사실로 사용하지 않는다.
4. 회수 가능성, 상대방 특정 가능성, 예상 비용과 시간을 먼저 점검한다.

## 형사 절차

1. 형법 제347조의 기망행위, 착오, 처분행위, 재산상 손해를 뒷받침하는 자료를 분리한다.
2. 고소장에는 직접 확인한 사실과 추정을 구분한다.
3. 수사기관 접수·보완 요구·사건번호·처분 결과를 날짜별로 기록한다.
4. 형사절차와 민사상 반환·손해배상 청구는 별도 상태로 관리한다.

## 민사 절차

1. 청구 근거, 원금, 이자 기산일, 피고 특정과 관할을 공식 자료로 확인한다.
2. 가까운 법원이 항상 관할 법원이라고 가정하지 않는다.
3. 소액사건심판·지급명령 등 절차 선택은 송달 가능성, 예상 다툼, 상대방 정보 수준을 함께 고려한다.
4. 제출 전 당사자 표시, 청구취지, 청구원인, 첨부자료와 계산을 사용자가 직접 검토한다.

## 송달·재판·확정

1. 판결 선고, 판결문 송달, 불복기간 경과와 확정은 서로 다른 상태다.
2. 무변론판결은 자동 결과가 아니라 법원의 절차 판단이다.
3. 수감자 송달 등 특수 송달은 현재 공식 규정과 사건 기록을 확인한다.
4. 집행이나 명부등재 기간을 계산할 때 구두 선고일과 집행권원 확정일을 혼동하지 않는다.

## 집행과 회수

1. 재산명시·재산조회, 채권압류·추심, 강제집행, 채무불이행자명부 절차를 별개로 관리한다.
2. 명부등재 또는 집행권원 확보를 실제 회수로 기록하지 않는다.
3. 신청 비용, 송달 상태, 제3채무자, 압류 대상과 실제 입금 여부를 각각 증빙한다.

## 사용자 통제 지점

로그인, 본인확인, 인증서, OCR 사실 확정, 법적 진술, 최종 제출, 결제와 포털 확인은 사용자가 직접 수행한다. Computer Use는 해당 지점 직전에 멈추고, 사용자가 결과 영수증이나 상태를 제공해야 사건 상태가 진행된다.
